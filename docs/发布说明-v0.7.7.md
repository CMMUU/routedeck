# Serylane v0.7.7

发布前验证中，尚未上传安装包。当前官网仍提供已发布版本。

- GitHub 仓库、发布流程、源码链接及 npm / Rust 应用包名统一为 Serylane / serylane。GitHub 当前仓库为 CMMUU/serylane；Gitee 路径、旧自动更新清单地址和签名文件别名仍保留兼容，不改动历史发布物。
- 隐藏导航、页面、日志、表格及弹窗滚动条，不占用滚动槽。鼠标滚轮连续平滑过渡，触控板细粒度滚动、横向手势和键盘操作继续可用；遵循系统“减少动态效果”，切页立即取消旧滚动。

- 统一产品、安装包、程序文件和快捷方式名称为 Serylane；保留数据目录、签名密钥、MSI 升级码及旧客户端所需的更新文件别名。
- 新增“开机静默启动”，仅登录自动启动时隐藏主窗口，手动打开仍显示窗口。与“登录时启动”“恢复上次运行状态”分别保存。
- 主“启动”按钮使用最新保存的网络模式，不再强制切换成系统代理。恢复时继续使用原配置和已保存的节点选择；TUN 授权不足或外部代理冲突仍暂停，不自动提权或强行接管。
- 日志页新增应用日志、级别及关键词筛选，停止核心后仍可查看。默认保留 3 天，可在设置调整为 1–90 天，与诊断报告独立保存；正文上限 256 KiB / 2,000 条，重复事件合并，达到容量时提前淘汰最旧条目。缩短期限立即清理，延长不会恢复已清理内容。不记录对话正文、订阅凭据或请求头。
- 系统代理预检细分 DNS、TCP、CONNECT、TLS 和超时原因，仅对失败的启动健康检查做一次有限重试；避免接管后重复检测的瞬时失败误停核心。保留安全回退和证书校验。
- 保留订阅自定义的健康检查地址、状态码及参数；补齐缺省参数，并排除明确的订阅建议提示项。
- “代理”页直接提供 OpenAI 稳定优先开关，与本地路由/Codex 接入无关；保留用户现有开关选择。应用日志记录稳定策略发生的切换。
- 修复策略版本更新会清空健康历史的问题：同一订阅、相同节点身份保留冷却期和近期失败记录；更换服务器、节点凭据或订阅时不继承旧证据。未指定时补齐 TCP 保活参数，不覆盖订阅显式设置。
- 网络预检使用独立错误码 `NETWORK_CHECK_FAILED`，不再混称核心启动失败；开机遇到临时 DNS、TCP、隧道或超时错误时有限重试，最多额外 3 次，手动操作/退出取消排队。证书、权限、配置及代理所有权错误不会因此反复启动。
- 将核心的超时、连接重置、证书和 DNS 错误按固定类别收集到应用日志，不持久化原始流量明细，也不把传输故障当作已确认的 Codex 模型流中断。

说明：外网预检成功或 OpenAI 返回 401 均不能证明模型流已验证。
本版本不能承诺恢复已经断开的模型流，另一台电脑的具体故障仍需结合新日志复核。
旧版本没有保存运行意图时，首次升级保守地保持停止；在新版本成功启动一次后，后续登录恢复才有明确依据。
安装迁移和开机行为需在隔离 Windows 环境完成实测后发布；未在用户正在使用的电脑上做重启或安装测试。
