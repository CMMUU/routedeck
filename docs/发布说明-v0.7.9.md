# Serylane v0.7.9

[[index|文档索引]] · [[软件设计说明书|软件设计说明书]]

## 更清晰的 macOS 双行网速

- 保留双行上下行布局和同源 S 图标，数字从整张托盘位图中拆出，改用 macOS 原生富文本；不再将数字一起缩小到 18pt 图标高度。
- 数字采用 9.5pt Medium 系统等宽数字，箭头和单位采用 8pt 字号；两行行高 10.5pt。数字右对齐、单位独立固定列，总宽度固定为 78pt，速率或单位变化不挤动旁边的菜单栏项目。
- 根据真实按钮几何位置修正原生单行基线，完整显示两行；不设置固定前景色，跟随菜单栏亮暗和选择状态。
- 菜单栏紧凑显示 B/K/M/G 等单位，悬停保留 B/s、KiB/s、MiB/s 等完整二进制速率单位。单位边界进位和超大速率不会被截成 999G。
- 关闭流量显示时明确清空原生标题、释放固定宽度并恢复彩色 S 图标；重新开启恢复双行。正常字体和备用像素绘制继续保留，全部使用同一份应用 S 图形。

## 验证范围

- 原生主线程测试创建独立的临时状态栏项目，直接调用生产排版逻辑；覆盖字号、两行高度、固定宽度、单位进位、关闭/重新开启。
- 1x/2x 实际 AppKit 绘制覆盖亮色、暗色和选中外观；像素检查要求普通外观下两行均完整、上下边缘没有裁切。单纯字符串尺寸测量不作为实际绘制通过的依据。
- 前端、Rust、品牌与发布同步脚本测试及六平台打包继续作为发布门禁。
- 本版不修改启动模式、用户配置、代理或 Codex 接入；Windows/Linux 显示行为保持原样。物理屏幕切换、安装升级及真实登录/重启验收独立记录，发版不会替换本机正在运行的应用。

## 发布与更新

沿用既有应用标识、数据目录、签名公钥和历史兼容附件。GitHub 发布通过的同一组安装包同步至 Gitee，摘要和签名验证完成后更新清单与官网下载路由；官网同步本版相关说明与部署。实际可下载版本以公开发布与下载区实时核对结果为准。
