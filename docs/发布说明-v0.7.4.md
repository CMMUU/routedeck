# Serylane v0.7.4

## 展示品牌更新

- RouteDeck 的展示品牌改为 **Serylane — 开源 Mihomo 桌面代理客户端**。更新窗口标题、侧栏、托盘、提示和独立预览，保留中文界面与已有功能。
- 接入新生成的透明蓝色 S 图标，使用 Tauri 官方 CLI 生成桌面平台及侧栏尺寸；旧 M 标记源图保留，图标更新不改变安装或数据身份。
- 项目官网地址为 [serylane.cmmuu.com](https://serylane.cmmuu.com)。官网部署、可访问性和下载链接需另行验收；这份发布说明不表示网站已经上线。
- README 保留 RouteDeck、mihomo-codex 曾用名说明，方便已有用户识别同一项目。

## 保持既有安装与更新身份

- 安装名称暂保留 `RouteDeck`，主程序、npm／Cargo 名称仍为 `routedeck`，Linux 内部包名仍为 `route-deck`。安装器、系统卸载列表、登录启动项或部分系统界面仍出现旧名称属于兼容安排。
- 保留 `com.cmmuu.mihomodesktop`、用户数据目录、`mihomo-tun-helper` 与服务标识；不因展示更名迁移或重置订阅、规则、设置和历史版本。
- 保留现有 GitHub/Gitee 仓库与更新清单、`RouteDeck_…` 安装包名称及签名验证公钥；继续同版本国内优先、GitHub 备用。历史包、签名与标签不重写。
- 保留 Codex 的 `routedeck` 提供方标识、lease 和备份格式；仅在用户新确认接入时写入 Serylane 显示名称。更名不扫描或改写已有接入配置，旧 RouteDeck 显示名称的 lease 仍可识别和恢复，不改变保存、启用路由、接入 Codex 的独立操作与安全确认。
- 品牌检查显式区分展示名称和安装身份，并守护旧更新地址、文件命名及签名公钥，避免全局替换造成旧版无法更新。

## 验证与使用边界

本次品牌调整不包含真实网络稳定性的新承诺。Windows TUN 仍为实验性功能；自动化测试或打包成功不代表真实 Codex 长会话、TUN 或所有平台安装流程已经验收。兼容路由默认关闭，切换节点不能无缝恢复已经中断的数据流。

本说明不代表版本已正式发布、国内镜像已同步或本机已安装。检查和下载更新不会停止代理；安装仍需用户确认，安装及重启可能中断连接，请避开重要会话。现有 RouteDeck 用户不应仅因展示更名而卸载软件或清空应用数据。
