# Serylane v0.7.5

## 主「启动」默认使用系统代理

- 点击应用顶部主「启动」按钮，默认进入 **启动 Mihomo 核心并启用系统代理** 的流程，不再因上次保存的是仅核心模式而只启动核心。
- 明确点击「TUN 模式」时仍按 TUN 流程运行，不替换为系统代理；已有权限要求、启动预检和错误提示继续适用。
- 程序代理中的程序启动与独立路由服务操作仍不自动修改系统代理／TUN；这些操作不是 Mihomo 核心启动入口。路由默认关闭，保存设置、启用服务、接入 Codex 仍是独立操作，不会由主「启动」自动接入 Codex。
- 这是用户主动点击主按钮后的默认行为调整，不是后台自动接管网络；仍应避免与其他代理客户端同时启用系统代理或 TUN。

## 启动失败与状态保护

- 网络模式保存失败时不继续启动；启动失败后尝试恢复之前的网络模式，不自动重启旧会话，恢复失败会明确提示。
- 端口预检或进程创建失败后恢复到可重试状态，不会一直卡在“正在启动”；已运行实例和正在处理的操作仍受保护。
- 启动期间避免设置保存相互覆盖，丢弃过期刷新结果；根据读回的运行、网络模式和系统代理状态判断成功，不把未接管显示为已开启。

继续使用 Serylane 展示品牌及蓝色 S 图标。安装名称 `RouteDeck`、`routedeck` 主程序、应用与 helper 标识、数据目录、GitHub/Gitee 更新地址、`RouteDeck_…` 安装包命名和签名公钥均保持不变。

## 验证与使用边界

文档描述本轮修改的源码行为，不表示 v0.7.5 安装包已发布、国内镜像已完成或本机已安装。自动化测试和构建检查不等于真实网络验收；Windows TUN 仍为实验性功能，兼容路由与灾备策略不保证永不断线，切换节点不能续接已中断的数据流。

检查和下载更新不会停止代理；安装仍需用户确认，安装及重启可能中断连接，请避开重要会话。发布验收以本版本工作流、签名和实际附件为准。
