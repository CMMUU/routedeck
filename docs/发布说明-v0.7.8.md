# Serylane v0.7.8

## 登录后保持上次启停状态

- 将启动选项整合为“不随系统启动”“登录后后台恢复上次状态”“登录后打开窗口并恢复”三种模式。已有自定义偏好继续保留，明确选择并保存新模式后才替换。
- 后台模式无需手动打开主窗口：上次开启则恢复保存的网络模式与选用配置，上次停止则保持停止。修改启动模式本身不启动或停止当前代理。
- 明确停止会先保存关闭意图，再清理代理。等待网络、恢复暂停或进程已经停止时，也可清除记忆的开启状态。关闭主窗口只隐藏界面，托盘退出和系统退出继续保留原启停记录。
- 临时网络预检失败后按 5、15、30、60 秒退避，之后每次等待 60 秒再尝试；停止和退出优先取消旧任务。权限、配置、证书或代理所有权冲突保持暂停，不自动提权或换模式。

## 系统登录项状态更清晰

- 区分保存的启动偏好、系统登录项登记、显式禁用标记与记忆的代理状态；核对操作不修改系统设置。
- 登录项写入后读回验证，保存失败时尝试恢复此前状态。Windows 回退保留原命令及 StartupApproved 值，不借助重新启用操作覆盖系统禁用状态。
- 保留未保存的模式草稿；刷新、保存失败和切换查看不会悄悄替用户选用其他启动模式。

## macOS 托盘统一为应用 S 标记

- 保留双行上下行速率布局，正常字体及备用像素绘制路径都从应用的同一份 S 图标生成，移除独立手绘 M。
- 动态托盘采用 macOS 模板着色，适配菜单栏亮暗背景；关闭流量显示后仍使用原彩色应用图标。
- 品牌检查和原生测试覆盖共享图形来源、两条绘制路径及大小单位，避免只更改提示文字而遗漏运行时图形。

## 发布与升级

- 本版沿用原应用/Helper 标识、数据目录、更新签名密钥和旧客户端兼容附件，不重写历史标签或签名文件。
- 安装包经六平台检查、签名验证与 Windows 隔离安装检查后公开；Gitee 同步同一份字节，全部附件校验通过后才发布更新清单及官网下载目录。
- 附件读取遇到截断或摘要不符时进行有界读取重试，仍严格拒绝不匹配的内容，不自动重试结果不明确的上传。增加可信 macOS 镜像执行器选项，用于诊断跨区域上传停滞。
- 后续发版固定包含 GitHub 代码与 Release、Gitee 代码与 Release、官网文案和部署，以及公开版本、文件和下载路由回验。任一环节未完成时不视为整次交付完成。

自动化测试覆盖持久化、取消和退出清理，不等同于每台电脑的真实登录、重启或 TUN 环境验收。安装仍需用户确认；本次发布不会自动替换正在运行的应用、改动当前代理或重新接入 Codex。
