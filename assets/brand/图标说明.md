# Serylane 应用图标

## 当前图标：Serylane S 标记（0.7.4 起）

透明背景上的蓝色折带 S 标记。应用侧栏与各桌面平台图标使用同一份源图；缩放和容器格式转换由 Tauri 官方 icon CLI 完成，没有重新绘制或修改源标记。

- 来源：2026-09-08 在本任务中由 Codex 内置 ImageGen 生成并确认的新 S 图。
- 原生成文件：`exec-57caa7a3-6141-4310-9f91-f8aa51e3660a.png`；项目内原样保存为 `serylane-icon.png`。
- 源图规格：1254 × 1254 RGBA PNG，透明外缘；SHA-256 为 `3027336ffc8474cc276b31cd30d240bed29120f8e5450d8cd284bd645537f570`。
- 侧栏与隔离预览：`app-icon-128.png`，128 × 128 PNG，与本轮 Tauri 生成的 `src-tauri/icons/128x128.png` 内容一致。
- 平台图标：`src-tauri/icons/` 中现有 17 个桌面 PNG、ICO、ICNS；其中 Tauri 配置直接引用 `32x32.png`、`128x128.png`、`128x128@2x.png`、`icon.ico` 和 `icon.icns`。默认窗口及托盘读取这些平台资源。
- v0.7.7 起安装名称与主程序统一为 `Serylane` / `serylane`；原 bundle identifier、数据目录和更新签名继续保留。
- v0.7.8 起，macOS 开启流量监控后的正常字体和备用像素路径都从同一个 `128x128.png` 生成 S 轮廓，不再绘制旧 M。菜单栏动态图标采用系统模板着色，以适配亮暗背景；关闭流量监控时使用原彩色 S 图标。

### 格式生成

先使用 CLI 的独立输出目录，再将桌面文件复制到 `src-tauri/icons/`，将 `128x128.png` 复制为侧栏 `app-icon-128.png`。本轮临时输出位于忽略的 `src-tauri/target/`；CLI 同时生成的 iOS／Android 素材未加入桌面发布范围。

```bash
npm run tauri -- icon assets/brand/serylane-icon.png -o src-tauri/target/serylane-icons
```

## 历史图标：RouteDeck / mihomo-codex

RouteDeck 0.6.0–0.7.3 沿用原 mihomo-codex 图标。以下保留原始设计提示和源图文件名，供追溯与重新生成；它们不是当前图标，也不是当前展示品牌。`mihomo-codex-icon.png` 原源图保持不变。

设计名称：双路汇聚。

深靛紫色圆角方形底板，白色至浅紫色的双路由 M 形标记，青色与紫色端点。应用图标与侧栏品牌图使用同一份设计。

- 生成方式：Codex 内置 ImageGen。
- 设计源图：`mihomo-codex-icon.png`，1254 × 1254 RGBA PNG，保留透明外缘。
- 当时的侧栏输出：`app-icon-128.png`；该输出位置现已更新为上述 S 标记。
- 当时的各平台安装图标：由 Tauri CLI 生成，输出至 `src-tauri/icons/`；这些输出位置现已更新。
- 应用名称、bundle identifier、用户数据目录不因图标变化而改变。

### 原生成提示词

Create one production-ready macOS icon for mihomo-codex, a network routing and AI connectivity utility. Transparent canvas around a centered midnight-indigo/violet squircle. A bold original M-shaped routing mark made from two joined near-white/lavender paths, cyan and violet terminal accents, generous negative space, readable at 16–32 px. Front-on native Apple-style craftsmanship with modest depth. No words, badges, existing company logos, or multiple variants.

### 历史格式生成命令（仅供溯源，不用于当前版本）

```bash
npm run tauri -- icon assets/brand/mihomo-codex-icon.png -o src-tauri/target/legacy-mihomo-icons
```

项目当前发布桌面版本，只维护本项目使用的桌面 PNG、ICO、ICNS；移动端产物不代表应用已支持移动平台。
