# 官网验收记录

验收日期：2026-09-08（Asia/Shanghai）。本记录描述本地实现，不代表已部署到公网。

## 设计对照

已对照获确认的首屏、功能/路由、下载/FAQ 三张设计稿与真实浏览器截图。

1. **结构**：三段连续页面，保持左文右产品预览、开放三列功能、宽玻璃路由说明、下载与 FAQ 的层级；不是整张图片或宣传海报。
2. **比例**：桌面标题、留白、导航、完整 Windows 窗口与下方技术栏保持原稿关系；系统中文字体与生成图存在正常字形差异，非像素级复刻。
3. **视觉**：同一冰白/深蓝/蓝紫环境光色系，磨砂仅作用于背景；标志统一为同源 S，控件与滚动条采用细圆角。
4. **内容**：首屏主标题、说明、CTA 和平台说明保留，没有添加眉题、性能指标或在线成功状态。
5. **操作**：产品图示为不可操作的关闭/未接入状态；真实操作仅为页面导航、平台选择、下载链接、FAQ。路由三步依然独立，站点不会接入 Codex。

有意偏离概念稿：根据真实发布资产更新下载按钮、版本和缺包提示；限定配置回滚、应用内更新校验、异常退出恢复、敏感内容持久化等文案；窄屏使用纵向布局与收起式导航。这些是事实准确性和响应式需求，不是新增产品功能。

## 已执行检查

- Codex 隐藏内置浏览器：1504×1046 桌面三段与 390×844 手机首屏、菜单、下载、校验文档截图，未打开用户桌面窗口。
- 320、390、768、1024、1440、1920 六种宽度，DOM 宽度检查无横向溢出。
- 打开/关闭菜单、Escape 关闭并归还焦点、六种系统/架构下载 URL 与主按钮顺序、Home 键切回 Windows 并移动焦点、FAQ 鼠标与键盘展开/收起、文档导航均通过。
- Cloudflare 本地运行时实际返回：首页与文档 200；`.html` 文档别名重定向到无扩展路径；未知页面 404；robots、sitemap、PNG、CSP 与缓存头正确。浏览器无 error/warn 日志。
- `pnpm test`：6 个 HTML、125 个内部链接/资源、canonical、sitemap、JSON-LD、静态边界、5 组离线下载交互回归均通过。
- `wrangler deploy --dry-run` 通过。只上传 `public/`，所有生产页面与素材合计约 100 KB（压缩前，不含安装包）。

截图备注：隐藏浏览器对超长 full-page 页面偶尔出现滚动分块拼接重复；验收和交付以各区段正常视口截图为准，不把拼接伪影当作页面重复内容。
